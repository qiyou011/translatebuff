## 👋🏻 Начало работы и сообщество

Цель Translatebuff — дать изучающим языки удобный, интеллектуальный и персонализированный опыт обучения. В эпоху ИИ это стало возможным, но на рынке все еще мало продуктов, которые действительно закрывают эту потребность. Поэтому мы решили создать такой инструмент сами.

Если вы пользователь или разработчик, Translatebuff может стать важной частью этого пути. Проект активно развивается, и мы будем рады сообщениям о любых проблемах.

## ✨ Возможности

Translatebuff превращает обычное чтение в интернете в иммерсивный процесс изучения языка.

### 🪄 [Пользовательские AI-действия][docs-tutorial]

Превращайте выделенный текст в многоразовые AI-инструменты под свой способ чтения и обучения. Настройте промпты и поля структурированного ответа, выберите провайдера, модель и значок, а затем запускайте действие прямо с панели выделения для поиска слов, переписывания, резюмирования, объяснения или собственного сценария.

Начните со встроенных шаблонов **Словарь** и **Улучшение текста** либо создайте действие с нуля.

### 🔄 [Двуязычный режим / Только перевод][docs-tutorial]

Переключайтесь между двумя режимами отображения перевода. **Двуязычный режим** показывает исходный текст рядом с переводом, что удобно для обучения и сравнения. Режим **только перевод** заменяет исходный текст и делает чтение чище.

Если перевод уже включен, расширение автоматически переведет видимый контент заново при смене режима, без перезагрузки страницы.

### ✨ [Перевод выделенного текста][docs-tutorial]

Выделите любой текст на странице, чтобы открыть умную панель инструментов. **Перевод** выводит результат в реальном времени, **объяснение** дает подробный разбор под ваш уровень, а **озвучивание** читает текст вслух через TTS.

Панель автоматически остается в пределах окна, поддерживает перетаскивание и работает на любых сайтах.

### 🧠 [Перевод с учетом контекста][docs-tutorial]

Позвольте ИИ понимать полный контекст читаемой страницы. Translatebuff извлекает заголовок и краткую Markdown-версию содержимого, чтобы перевод был точнее и лучше соответствовал ситуации.

Технические термины переводятся в рамках предметной области, литературные выражения сохраняют оттенки смысла, а неоднозначные фразы трактуются по окружающему тексту.

### 🎬 [Перевод субтитров][docs-tutorial]

Переводите субтитры YouTube прямо в видеоплеере. Смотрите контент на иностранных языках с переводом рядом с оригинальными субтитрами.

### 🔊 [Озвучивание текста (TTS)][docs-tutorial]

Слушайте выделенный текст с качественными AI-голосами. **Edge TTS** полностью бесплатен и предлагает 150+ голосов для 80+ языков, включая китайский, английский, японский, корейский и многие другие. Можно настроить скорость, тон и громкость.

Автоопределение языка и сопоставление голосов помогают выбрать подходящий голос. Длинный текст делится по естественным границам предложений, а следующий фрагмент предварительно загружается.

### 📦 [Пакетные запросы][docs-tutorial]

Снижайте расходы на API до 70% благодаря интеллектуальному объединению запросов. Translatebuff группирует несколько переводов в один API-вызов, уменьшая накладные расходы и использование token без потери качества.

Система включает повторы с экспоненциальной задержкой и автоматический fallback к одиночным запросам, если пакетная обработка не удалась.

### 🤖 [Встроенный ИИ-перевод][docs-tutorial]

Войдите и сразу переводите — свой API-ключ не нужен. Встроенный сервис ИИ-перевода Translatebuff автоматически выдает ключ и предлагает несколько моделей ИИ, чтобы вы выбирали подходящую модель для каждой функции.

Также доступен стандартный перевод через Google Translate и Microsoft Translate.

### Сборка и упаковка

Репозиторий выпускает две редакции с независимыми бэкендами и карточками в магазине: `cn` (translatebuff.cn) и `global` (translatebuff.com). Всегда собирайте через `scripts/pack.mjs` — прямой запуск `wxt zip` обходит доменные проверки, которые разделяют редакции.

```bash
node scripts/pack.mjs test --edition global                        # test build
node scripts/pack.mjs store --edition global --channel global-zip  # store build, one channel
node scripts/pack.mjs store --edition global --all                 # store build, every channel
```

Уберите `--edition global`, чтобы собрать редакцию cn. Артефакты появятся в `.output/`; загрузите `.output/chrome-mv3-global/` как распакованное расширение, чтобы попробовать сборку. Тестовая сборка читает локальный `.env.global` (в gitignore) — переменные для каждой редакции см. в [.env.example](../.env.example), модель редакций — в [FORK_GUIDE.md](../FORK_GUIDE.md).
