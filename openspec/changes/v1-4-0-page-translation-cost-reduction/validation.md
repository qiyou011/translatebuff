## 代码审查与回归

独立架构评审结论为「审查通过」。代码审查发现的四项问题均已修复并复审关闭：

1. 先处理401/429，再释放并发槽及调度等待请求；超时或取消不能提前释放未结束的底层调用。
2. 输入翻译的前置摘要与页面请求隔离；测试中页面4个请求饱和，输入摘要仍可完成。
3. HTML扫描仅做ASCII大小写转换，避免 `İ` 改变字符串长度。
4. 自闭合标签压缩时隔开斜杠，防止把标记0变成0/。

上述相关三个测试文件独立复审30/30通过。另覆盖部分字段失败仅降级该项、跨标签取消、HTML缓存sentinel复用、429保持批次重试、100条MT聚合及编码后载荷分批。
