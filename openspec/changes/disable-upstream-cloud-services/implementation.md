新增 14 条精确模块重定向及对应源指纹，服务适配器在 `src/fork/upstream-services/`；抽取任译喵身份纯叶子，修改既有 fork 模型展示/输入翻译反馈及博客叶子。不改上游引擎源文件、模型分类、配置 schema、迁移、全局重试、消息协议、既有会员同步算法或自有接口域名。

核心行为：旧上游模型引用在请求前解析为合格任译喵模型；无候选前置提示。语言检测旧引用降级本地；上游认证为空、RPC 本地拒绝、后台状态为空、云笔记处理器不运行、博客查询不启动。正常 local 路径保留，兼容不写配置，历史笔记数据不删除。

代码初审指出两处真实消费者缺口，已补最小包装：页面 validator 在旧引用无候选时提示并退出；字幕翻译抛局部不可重试错误，原协调器记录失败并结束 loading，避免把空译文登记成成功。可选字幕摘要/分段继续允许 null 降级。这两处不复制引擎，正常路径及其余导出复用原件。

浏览器另外发现 API 提供商页使用独立的 `feature-providers/index.tsx` 区块，而非 popup 的 selector list。新增 fork 区块覆盖，复用原写入 hook、说明截断工具和布局组件，仅隐藏笔记建议行、展示实际模型；popup 列表/摘要也不再展示笔记建议。该区块影响分析 LOW，直接调用为 ApiProvidersPage，已补实际区块渲染测试（先失败后修复）。
