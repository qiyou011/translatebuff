4. 微软官方文档支持 textType=html，并要求资源/认证。alignment 受语言对等限制，且不适用于 HTML 输入；不作为该方案唯一依赖。[Translate 官方接口](https://learn.microsoft.com/en-us/azure/ai-services/translator/text-translation/reference/v3/translate)、[资源与认证](https://learn.microsoft.com/en-us/azure/ai-services/translator/how-to/create-translator-resource)。
5. 本地模型对齐属于另一项模型/运行时依赖，且不能凭空恢复服务已省略的第二个词。没有性能与 P0 证据，不推荐把它直接写成已选路线。
