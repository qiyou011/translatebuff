## 实验覆盖与复现

所有实验使用真实 `createPageTranslationQueues`、批处理和服务返回，不硬编码翻译。通过本机现有代理联网；实验期间使用 Node 原生 TextEncoder，不修改产品或共享测试配置。

| 实验                                 | 样本与方向                                                                                                | 记录                                |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| protocol-probe.test.ts               | 两服务各 27 组原型提取文本、当前首段、语序/重复词/嵌套/换行；中文全部、日语和德语补充样本，共 84 个翻译项 | protocol-probe-results.json         |
| marker-candidates.test.ts            | 微软 8 种编码 × 7 个样本 × 中文/日语/德语，共 168 项                                                      | marker-candidates-results.json      |
| microsoft-minimal-html-probe.test.ts | 微软 4 种最小标签编码 × 7 个样本 × 3 个目标语，共 84 项                                                   | microsoft-minimal-html-results.json |

最后一项仅在测试 fetch 包装器中对合成的最小标签载荷撤销转义，以探测专用适配是否可行。实际队列流程和服务都是真实的，但**该项不是当前生产传输的原样运行**；生产通用 HTML 禁止和纯文本转义未改动。证据中保存了实际网络 body。

普通运行跳过联网实验。复现需设置 `SKIP_FREE_API=true`、`RUN_FORMAT_PROVIDER_PROBE=true`、`HTTPS_PROXY=http://127.0.0.1:7897`、`NODE_USE_ENV_PROXY=1`，用 `pnpm exec vitest run <实验路径>`。在线重跑会更新采集 JSON；审查应先保存本轮原始证据。

## 微软：计数成功不等于格式可恢复

| 候选                           | 实际反例                                                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------ |
| 无空格 `⟦B0⟧` / `⟦H1⟧`         | 日语 REORDER 丢失粗体开始/结束及高亮结束标记；中文重复词 account 未翻译                                                  |
| 加空格的同类标记               | 日语 REORDER/BREAKS 丢标记；德语 REPEAT 高亮边界移动到被强调词之后，形成空范围                                           |
| 纯数字 `⟦0⟧`                   | 日语 REORDER 丢边界；中文 F01/F24 输出缺少 for people 的对应描述                                                         |
| `{{B0}}`                       | 中文 F24 丢标记，日语多个样本失败                                                                                        |
| `[[B0]]`                       | 中文 LIVE-1/NESTED 及日语多个样本失败                                                                                    |
| 转义后 XML 标记                | 中文 F01/F24 标记损坏，日语 LIVE-1 损坏                                                                                  |
| ZXQSTART / ZXQEND              | 标记计数齐全，但中文 REORDER 粗体范围包含“并”，日语 REORDER 范围不能完整包住“保存更改”的译文；德语重复词范围包含额外谓语 |
| `⟪B0⟫`                         | 日语 F24/REORDER、德语 REORDER 丢标记                                                                                    |
| `【B0】`                       | 中文 F01/F24/REORDER/NESTED 及多个日语样本失败                                                                           |
| 最小 span id / data 属性、b id | 中文出现弯引号、标签或属性被翻译、正文吞入开标签；部分其他方向正文重复或强调扩大                                         |
| 最小自定义标签 rfb0 / rfh1     | 中文 REPEAT 把第二个 account 的高亮映射成“但必须验证”；德语同类错位。标签完整但语义错位，不能靠语法校验修好              |

例如自定义标签输入 `The <rfb0>account</rfb0> is active, but the <rfh1>account</rfh1> must be verified.`，返回 `<rfb0>账户</rfb0>是活跃的，<rfh1>但必须验证</rfh1>。`。这是中文主方向中的重复词 P0 反例，并非仅由额外语言测试导致暂停。

这些反例说明本轮候选不能作为已验证协议；不构成“微软所有可能方案都不可能”的证明。继续实施需要先修订并验证协议方案，不能自动选择计数最好的一种，也不能通过逐短语翻译、改服务或降低 P0 绕过已确认范围。

## 谷歌：HTML 通道可用，但需独立原子及语义审计

27 组提取文本的中文请求保留了本轮的属性 ID；BREAKS 样本保留两次换行和空行。既有 `assertHtmlAttributeMarkerIntegrity` 可复用来拒绝缺失、重复和新增属性；它不能证明嵌套边界、文字完整和原子唯一性。

实际日语 REPEAT 响应把 `ZXQATOM2QXZ` 既输出在 translate=no span 内，又重复在 span 外，属性校验仍通过。实际 LIVE-1 日语响应的粗体还扩大到例举应用。新路径必须单独校验原子和边界，安全重建并拒绝缓存损坏结果；正常 P0 语义对应仍须实际浏览器验收。

`provider-boundaries.test.ts` 使用本轮真实响应验证上述复用边界，同时注入缺失/重复/新增属性确认现有守卫。测试通过证明问题可复现，**不是**说明新产品能力通过。
