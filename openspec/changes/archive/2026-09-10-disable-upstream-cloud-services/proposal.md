## Why

任译喵持续合并 Read Frog 上游并复用其核心翻译逻辑，同时独立维护会员、登录和输入翻译等 fork 特性。上游 `/api/identity`、`/api/rpc`、`/api/blog` 对应的云服务不属于任译喵产品能力，仅替换域名或隐藏部分 UI 不能保证停止请求。

本次通过现有 fork 模块重定向建立最小禁用边界：不请求这三类上游服务，不破坏自有业务，不扩大上游核心代码分歧，把后续同步成本集中到少量明确的适配点。

## What Changes

- 经用户后续确认，补齐自有 UI 的发行版品牌与九种语言文案；托管模型选项和翻译中心卡片仅显示模型名；静态预览跟随界面语言，不新增翻译请求或持久化配置。归档决策与剩余检查见 [archive-closeout.md](archive-closeout.md)。

- 国内、海外版本的开发、测试、正式构建统一禁用上述上游服务；保留上游源码与依赖，不在原文件逐处删除调用。
- 同时覆盖 UI 入口、后台触发和客户端请求出口；上游云服务不可用不等于任译喵用户退出登录。
- **【破坏性变更】** 停止支持上游账号会话、托管 AI/配额/转录、Notebase 云保存及上游博客通知。已有上游云配置和待保存数据保留但不执行，不伪造操作成功。
- 保留上游翻译引擎及当前支持的非上游 provider 路径。旧配置仍引用上游托管模型时，在请求前临时解析到已有、启用且满足能力与现有凭据条件的任译喵模型；没有候选则前置结束并引导登录或选择模型，不请求上游、不自动重试。此兼容使用现有额度规则，不代表免费调用。
- 语言检测单独处理：旧上游模型引用降级为本地检测，不自动换成付费模型；有效的非上游 LLM 检测保持原行为。笔记建议在当前 fork 已无执行入口，本次不恢复。
- 页面、划词、输入、普通字幕翻译及自定义动作保留；字幕摘要/分段继续受模型能力约束。任译喵登录会员、官网联动及 Discord 输入翻译行为不变，普通字幕不因禁用云转录被关闭。
- 不新增配置批量迁移或扩大模型重指向范围；运行时兼容不写回配置，现有模型种子、登录和凭据同步行为保持原样。
- 沿用重定向指纹、fork 测试和边界检查，明确不定期合并时的审查、验证与回滚方式。

## Capabilities

### New Capabilities

- `fork-upstream-cloud-isolation`：三类上游云服务的禁用、旧模型运行时兼容、语言检测降级、自有能力保留及合并维护边界。

### Modified Capabilities

- `fork-backend-repoint`：将既有“v1 保留 better-auth、由 fork 后端兼容”的要求改为客户端 fork 禁用适配；其余环境变量与域名守卫要求不在本次调整。

## Impact

- 基线：`change/fork-foundation@cc6a65974dbec43c9643f246d26ccff65701d2bf`；工作分支：`feat/disable-upstream-cloud-services`。
- 主要实现位置：`src/fork/**`；`wxt.config.ts` 增加重定向及构建接入，既有九种 locale 补齐文案，不新增 allowlist 例外。
- 受影响接口是扩展内上游服务调用，不是对整个网站或所有 `/api/*` 的网络封锁。自有认证、claw、上报、官网跳转和翻译网关不改域名、不改协议。
- 不涉及后端开发、数据库迁移、新依赖、版本发布或历史数据删除。本次工件完成不表示功能已实施或浏览器验收已完成。

## Non-goals

- 不建设通用能力插件框架、远程开关、管理后台或持久化能力配置。
- 不重写翻译引擎，不为上游 RPC 模拟完整服务器，不替上游云服务开发任译喵替代品。
- 不进行全仓重构、无关性能优化、依赖清理或其他上游服务的顺带屏蔽。
